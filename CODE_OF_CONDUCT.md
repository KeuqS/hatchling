# Code of conduct

Hatchling is built in public by people who disagree about code. Keep the disagreement about the code.

## Expected

- Be kind, and assume good faith.
- Be precise. Criticism comes with evidence: a failing test, a trace, a line of code.
- Welcome newcomers. Everyone here once asked their first question.
- Credit other people's work.

## Not accepted

- Harassment, insults, or personal attacks, in any project space.
- Discriminatory language or imagery.
- Publishing anyone's private information.
- Disclosing a vulnerability in public before it's fixed (see [SECURITY.md](SECURITY.md)).

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and block people who break these rules. To report a problem privately, use GitHub's **Report content** option on the comment or issue, or contact a maintainer through their GitHub profile.

This applies to the repository and every space that represents the project.
